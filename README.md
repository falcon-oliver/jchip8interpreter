# Installation

## Requirements
```
Gradle 8.14.3
```
```
Java 17.0.12
```
## From release

Download <a href="https://github.com/falcon-oliver/jchip8interpreter/releases/download/1.0/app.jar">here</a>

```bash
java -jar app.jar
```

## From source
```bash
git clone https://github.com/falcon-oliver/jchip8interpreter.git
cd Chip8-interpreter
gradle build
gradle run
```
